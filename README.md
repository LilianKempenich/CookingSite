# Crumb

A personal baking and cooking site: pantry tracker, recipe box, shopping list and meal planner, all in one HTML file (`index.html`).

- **Pantry**: stock levels, running-low alerts, quick add
- **Recipes**: paste-to-import, ingredient and step checklists, scaling (by factor, servings, what you have, or pan size), step timers, tags, search, related recipes
- **Shopping list**: in store / online / both, search links for your chosen stores, move bought items into the pantry
- **Meal plan**: weekly view that totals ingredients, checks the pantry, and fills the shopping list

- Claude version (saves to your Claude account, Claude features built in): https://claude.ai/artifact/6fQvBFXEdmhmd97ne12uci
- GitHub Pages version: https://liliankempenich.github.io/CookingSite/

The GitHub Pages version saves to the browser you use it in. "Find where to buy" works there with built-in suggestions; add your own Anthropic API key in Settings to have Claude answer instead (the key stays in your browser).
