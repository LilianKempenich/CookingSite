# Little Whisk

A personal baking and cooking site: pantry tracker, recipe box, shopping list and meal planner, all in one HTML file (`little-whisk.html`).

- **Pantry**: stock levels, running-low alerts, quick add
- **Recipes**: paste-to-import, ingredient and step checklists, scaling (by factor, servings, what you have, or pan size), step timers, tags, search, related recipes
- **Shopping list**: in store / online / both, search links for your chosen stores, move bought items into the pantry
- **Meal plan**: weekly view that totals ingredients, checks the pantry, and fills the shopping list

Live version (with cloud saving and Claude features): https://claude.ai/artifact/6fQvBFXEdmhmd97ne12uci

Opened as a plain file or hosted elsewhere, it saves to that browser only, and the Claude-powered buttons are hidden.
